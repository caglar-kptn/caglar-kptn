### 🏆 Featured Projects

* **🎬 MEDDAH — Audio Description Platform (Tech for Good):** An AI-powered accessibility platform designed to make video content more accessible for visually and hearing-impaired users. It generates synchronized subtitles and context-aware audio descriptions for uploaded videos and YouTube content. Built with a React frontend, .NET backend, and a Python-based AI pipeline using Qwen VLM for scene understanding and Groq API for language processing, with Turkish and English output support.

* **🎮 Party Arena — Mobile Party Game:** A modular mobile party game currently being developed with Godot and GDScript. The project combines multiple mini-games under a shared game architecture with player and bot support, reusable gameplay systems, round lifecycle management, scoring flows, responsive UI/HUD components, and mobile-oriented controls. The architecture is designed so new mini-games can be integrated without breaking the common party-session flow.

* **📄 CVWise — AI Resume Evaluation Platform:** An AI-powered resume analysis platform built with React, FastAPI, Python, SQLite, Machine Learning, and Groq API. It evaluates ATS compatibility, content structure, skills, experience, education, measurable achievements, and industry-specific keywords. A hybrid scoring system combines rule-based analysis with a custom-trained machine learning model, while the LLM layer generates personalized improvement suggestions.

* **🎙️ SLess — Deep Learning Speech Enhancement Platform:** An AI-powered speech enhancement application that uses five trained deep learning models to reduce background noise from audio recordings. Users can enhance audio with a single model or compare models side by side using synchronized A/B playback. The platform also provides interactive waveform, spectrogram, histogram, and 3D energy visualizations using WaveSurfer.js and Three.js.

* **📊 DataShift Studio — Desktop Data Processing Application:** A Python and PyQt6 desktop application designed for importing, exploring, and processing CSV and Excel datasets. Pandas is integrated with QAbstractTableModel and QTableView for efficient tabular visualization, while the application follows a modular workflow structure for profiling, filtering, transformation, and future data-processing operations.

* **🔐 Secure AI Survey System:** A full-stack survey platform featuring AI-assisted survey generation, reusable templates, QR-code distribution, and automated response tracking. It includes a Python-based multi-step verification engine using face recognition, ID scanning, location validation, and contact verification to control access to targeted surveys. Built with React, Node.js, MongoDB, and Python.

* **📄 Optical Form Processor:** An automated exam grading system combining digital image processing with a mobile interface. Built with Flutter, Python, OpenCV, and SQLite, the system detects marked answer bubbles, compares them against dynamically created answer keys, automatically calculates exam results, ranks students, and provides centralized result management.

* **🎙️ Voice-Enabled Mobile Translator:** A Kotlin-based mobile translation application utilizing Speech-to-Text and Text-to-Speech technologies for voice-driven translation workflows. It includes an on-device Room Database for storing personalized dictionary entries and supporting reusable user-specific vocabulary.

* **☕ CafeByte Automation:** A JavaFX-based desktop restaurant management application designed for real-time order and table management. The system uses a cloud-based Supabase backend to synchronize restaurant operations and provides a centralized interface for managing tables, orders, and related workflow data.

* **🏦 Desktop Banking Application:** A Python desktop banking application built with Tkinter and SQLite. It includes secure user authentication, account management, user-specific IBAN generation, money transfers, transaction history, transaction filtering, and persistent management of account balances and transaction records.
